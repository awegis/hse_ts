## ДЗ 1. Анализ временного ряда продаж

Исследовала продажи товара 21755 - LOVE BUILDING BLOCK WORD из датасета [Online Retail](https://archive.ics.uci.edu/dataset/352/online+retail). 
Для загрузки датасета внутри ноутбука нужен интернет!

Цель - проверить качество данных, изучить изменение продаж, сезонность и стационарность ряда.

### Подготовка данных

Показатель продаж - количество проданных штук по всем странам. Исключила отмененные операции, неположительное количество и неположительную цену. Осталось 654 записи.

Строки с пропусками в CustomerID оставила: номер покупателя не нужен для подсчета продаж.

Построила дневной, недельный и месячный ряды за период с 01.12.2010 по 09.12.2011. Дальше анализировала дневные данные.

### Качество данных

В 113 днях нет записей продаж товара. В 44 из них есть операции в датасете, а в 69 нет никаких операций.

Отсутствие записей занулила. Дополнительно проверила интерполяцию 69 неопределенных дней.

Метод IQR выделил 19 потенциальных выбросов. Их не удаляла.

### Изменение продаж

Среди дней с записями средние продажи составили 7,79 штуки, медиана - 6. С учетом подставленных нулей среднее составило 5,44, медиана - 3.

Среднее выше медианы из-за отдельных дней с большими продажами. Максимальные дневные продажи - 40 штук.

Скользящие среднее и стандартное отклонение показали, что уровень и разброс меняются. В январе 2011 года они выше, летом ниже. Устойчивого роста не обнаружено.

### Сезонность

Использовала STL-декомпозицию с предполагаемым периодом 7 дней. Метод разделяет ряд на тренд, сезонную часть и остаток.

Выраженной недельной сезонности не нашла. Ее сила составила 0,172 при заполнении нулями и 0,082 при альтернативной обработке. Корреляция с лагом 7 дней после удаления тренда также слабая.

В остатках сохранились заметные скачки, которые тренд и недельная составляющая не объясняют.

### Стационарность

Применила тесты ADF и KPSS при уровне значимости 0,05. Проверила исходный подготовленный ряд и первые разности.

При автоматическом выборе лагов тесты дали разные выводы. Для первых разностей KPSS выбрал 372 лага на 373 наблюдения. Дополнительно проверила стандартное правило legacy, которое выбрало 17 лагов.

При legacy результаты согласуются со стационарностью первых разностей в обоих вариантах обработки дней без записей. Вывод об исходном ряде зависит от обработки данных и настройки KPSS.

Установить библиотеки:

## ДЗ 2. Прогнозирование продаж

В работе сравниваются прогнозы продаж товара 21755 - LOVE BUILDING BLOCK WORD из датасета [Online Retail](https://archive.ics.uci.edu/dataset/352/online+retail). Цель - посмотреть, как качество прогнозирования зависит от модели, частоты данных и горизонта.

### Данные

Те же.

Пустые периоды приняты за нулевые зарегистрированные продажи. Неполные крайние недели и последний неполный месяц в недельный и месячный ряды не включались.

### Модели и оценка

Сравнивались три модели:

- наивная - прогноз равен последнему значению обучающего ряда;
- Holt - экспоненциальное сглаживание с затухающим трендом;
- Gradient Boosting - бустинг по трем предыдущим значениям ряда с рекурсивным прогнозом.

Данные разделены по времени: будущие наблюдения использовались для проверки, а не для обучения. Для каждой частоты модель обучалась один раз перед самым длинным горизонтом. Прогнозы на короткие горизонты оценивались по началу этого же тестового отрезка.

Рассчитывались MAE, RMSE, WAPE, MASE и ME. Основной критерий сравнения - MAE внутри одной частоты и горизонта. MAPE не использовалась, потому что в рядах есть нулевые продажи.

### Результаты

На дневных данных лучше была модель Gradient Boosting на горизонте 1 день, а на горизонтах 7, 31 и 61 день - наивная модель. На недельных данных Gradient Boosting показал лучший результат на 1 шаге, Holt - на 8 шагах. На горизонте 4 шага наивная модель и бустинг показали одинаковую MAE. Для месячных данных лучше сработал Holt на 1 шаге и наивная модель на 2 шагах.

### Ограничения

Результаты получены на одном тестовом отрезке, поэтому они могут измениться при другом временном разделении. Для месячных данных всего 12 наблюдений: 10 использованы для обучения и 2 для проверки. Поэтому выводы о месячных прогнозах особенно предварительные.

## ДЗ 3. Иерархическое прогнозирование продаж

Продолжение ДЗ 1 и ДЗ 2: те же правила отбора данных и те же модели, но теперь прогнозируется не один товар, а иерархия рядов - общий уровень продаж, группы товаров и отдельные товары. Прогнозы узлов согласуются между собой: значение родительского узла равно сумме прогнозов дочерних.

### Иерархия

В датасете нет готовых категорий, поэтому структура выбрана самостоятельно:

- уровень 0 - Всего: продажи всех товаров вместе;
- уровень 1 - 4 группы: Сумки (BAG), Формы для выпечки (CAKE CASES), Подсвечники (T-LIGHT), Прочие товары;
- уровень 2 - 12 нижних узлов: 11 отобранных товаров (по 3-4 самых продаваемых в группе) и узел Остальные товары.

Группы выделены по ключевым словам в названии, отбор товаров - по StockCode. Остальные товары - сумма всех прочих продаж, поэтому общий уровень совпадает со всеми продажами магазина. Отобранные товары покрывают около 5,2% продаж. Каждый товар относится ровно к одной группе, связи родитель-потомок однозначные. Товары отобраны по итогам обучающего периода, чтобы будущие продажи не влияли на структуру иерархии.

### Данные и ряды

Отбор как в ДЗ 1 и ДЗ 2: исключены отмененные операции, неположительное количество и неположительная цена. Единая частота - недельная W-SUN, 52 недели (2010-12-12 - 2011-12-04), неполные крайние недели исключены, пропуски занулены. Горизонты 1, 4, 8 недель; тест - последние 8 недель, обучение - 44 недели. Согласованность исходных рядов проверена: для каждой недели родитель = сумма дочерних.

### Модели и согласование

Те же три модели, что в ДЗ 2 (наивная, Holt, Gradient Boosting по 3 лагам с рекурсивным прогнозом), обучаются отдельно на каждом узле. Согласование реализовано через матрицу суммирования S и четыре метода:

- Bottom-up - родители собираются суммой прогнозов товаров;
- Top-down (прогнозные доли) - прогноз итога распределяется по долям прогнозов товаров на каждом шаге;
- Top-down (исторические доли) - то же, но доли считаются по обучающим данным;
- MinT (OLS) - наименьшие квадраты, поправляются все узлы сразу.

Доли и матрица S строятся только по обучающим данным, отбор товаров тоже выполнен по обучающему периоду - утечки из теста нет. После согласования условие родитель = сумма дочерних проверено для всех методов и моделей. Метрики те же, что в ДЗ 2: MAE, RMSE, WAPE, MASE, ME. Между узлами разного масштаба сравнивается WAPE.

### Результаты

Независимые прогнозы согласованы по-разному: наивная модель согласована автоматически, Holt расходится умеренно, Gradient Boosting сильно. Согласование гарантирует математическую согласованность, но не гарантирует рост точности. Для Holt лучшие результаты на уровне групп и товаров дает MinT (OLS) и по WAPE, и по MASE. Для Gradient Boosting общий уровень улучшает Bottom-up (WAPE 43,2% -> 32,7%), а на уровнях групп и товаров - Top-down (исторические доли). MinT (OLS) не ограничивает прогнозы снизу нулем: для Gradient Boosting получилось 65 отрицательных значений и большие WAPE на уровнях групп и товаров - это ограничение метода. Top-down (исторические доли) для Holt хуже, так как исторические доли не совпадают с долями тестового периода.

### Ограничения

Результаты получены на одном тестовом отрезке из 8 недель и могут измениться при другом разделении. Иерархия построена на отобранных товарах, покрывающих малую долю продаж; основной объем - в агрегированном узле Остальные товары.

### Как запустить

Установить библиотеки:

```bash
pip install pandas numpy matplotlib statsmodels scikit-learn ucimlrepo
```
